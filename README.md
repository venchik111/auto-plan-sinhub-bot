# Авто-планирование на неделю

Сервис принимает свободное описание планов, структурирует его через внешнюю LLM, показывает редактируемый черновик и записывает строки в персональный лист Google Sheets только после нажатия «Подтвердить и записать».

Веб-версия с тем же функционалом запускается на `http://localhost:8000`: в ней есть наводящие вопросы, ручной редактор целей и задач, а также правки черновика обычным текстом.

## Что уже поддерживается

- привязка Telegram-пользователя к персональной вкладке по её названию;
- текущая и следующая неделя, а также ручной формат `14.09-20.09`;
- выделение целей, сфер, задач, дней и планового времени;
- предупреждения о перегруженных днях и задачах без времени;
- правки черновика обычным сообщением до записи;
- запись в формат `Неделя | Цели недели | Сфера | Задача | День | Статус | Рефлексия`;
- автоматический статус новых задач `⏳`;
- повторное нажатие подтверждения не создаёт дубликат, потому что черновик удаляется после успешной записи.

## Настройка

1. Создай бота у `@BotFather` и положи токен в `.env`.
2. Установи OpenCode CLI: `npm install -g opencode-ai`. Авторизуй CLI один раз через `opencode providers login`; бот запускает `opencode run` как отдельный процесс, поэтому CLI сам управляет сессией и доступом к бесплатным моделям.
3. Для OpenCode оставь `LLM_PROVIDER=opencode`. Модели задаются через `OPENCODE_MODELS` в формате `opencode/provider-model`; при ошибке бот последовательно пробует следующую модель.
4. Создай Google Cloud service account, включи Google Sheets API, скачай JSON-ключ в `credentials/service-account.json`.
5. Открой доступ к Google Sheets на email сервисного аккаунта с ролью **Редактор**. Одной публичной ссылки «только просмотр» недостаточно для записи.
6. Скопируй `.env.example` в `.env`, проверь `GOOGLE_SPREADSHEET_ID`, путь к ключу и `OPENCODE_BIN`.
7. Установи зависимости и запусти:

```bash
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python -m app.main
```

## Важная проверка исходной таблицы

При регистрации бот ищет ФИО напрямую среди названий вкладок Google Sheets. Регистр, лишние пробелы, неразрывные пробелы и `ё/е` не влияют на поиск. Технические вкладки `Список студентов`, `Дашборд куратора` и `Инструкция` в регистрацию не попадают.

Если вставлено только начало названия вкладки, бот примет его только при единственном однозначном совпадении. После регистрации план записывается именно в найденную вкладку.

## Запуск веб-версии

```bash
./.venv/bin/uvicorn app.web:app --host 0.0.0.0 --port 8000
```

После запуска открой `http://localhost:8000`. Сайт использует ту же конфигурацию `.env`, OpenCode CLI и сервисный аккаунт Google Sheets.

В веб-версии подключение Skyeng выполняется кнопкой «подключить» рядом с расписанием. Откроется окно самого Skyeng, а пароль останется у Skyeng. Сессия сохраняется отдельно для текущего пользователя сайта, поэтому у разных пользователей могут быть разные направления и курсы. Переключатель «Учитывать расписание автоматически» включён по умолчанию: названия активностей и время добавляются в запрос к LLM без отдельной просьбы. Уроки, практики, тренажёры и тесты считаются заданиями на онлайн-платформе, а вебинары и практика с наставником — онлайн-созвонами внутри Skyeng.

Ручной helper оставлен только для локальной диагностики и не нужен для веб-версии:

```bash
./.venv/bin/python -m app.skyeng_login
```

В открывшемся окне войди в Skyeng вручную. Сессия сохранится локально с закрытыми правами. Сайт будет обновлять расписание при обращении к неделе, если сохранённым данным больше 7 дней.

## Пример сообщения

```text
На следующую неделю хочу закрыть долг по физике: в понедельник разобрать конспект,
во вторник решить задачи и в пятницу пересдать тест. Ещё две тренировки в среду и субботу.
На каждую учебную задачу примерно по часу, тренировка полтора часа.
```

Бот вернёт черновик, даст отредактировать его, а после подтверждения добавит строки в лист студента.

## Проверка

```bash
pytest -q
python -m compileall app
```

OpenCode подключается через CLI в режиме `run --format json`: prompt передаётся через stdin, а текст извлекается из JSONL-событий `type=text`. Доступность бесплатных моделей может меняться, поэтому список моделей и timeout вынесены в конфигурацию. Для альтернативного режима установи `LLM_PROVIDER=openrouter` и задай OpenRouter-переменные.
